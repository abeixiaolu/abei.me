# Pixel font sources

- `pixel-latin.ttf` is Press Start 2P from https://github.com/google/fonts/tree/main/ofl/pressstart2p. License is in press-start-2p.txt.
- `pixel-cjk.woff2` is Fusion Pixel 12px proportional Simplified Chinese from https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.10.25. The release includes OFL and component licenses retained in this directory.
